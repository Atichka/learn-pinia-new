# Learn Pinia

Проект для изучения управления состоянием в Vue.js с использованием Pinia.

## 🚀 Технологии

- Vue.js 3
- Pinia (менеджер состояний)
- Vite
- Vue Router

## 📦 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/atichka/learn-pinia-new.git
cd learn-pinia

# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build
```
